All four run in a browser

WebAssembly and X16 are served from this page. Apple2TS and a2gsemu-ia are separate browser emulators; the links above start them with the matching Freegemas disk.

Controls

Mouse to move and select; arrows to move; Space or Enter to confirm; H for a hint, R to reset, Esc for the title. X16 also accepts the keyboard joystick mapping and a gamepad.
