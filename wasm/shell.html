Controls & Input

Mouse Click & drag gems to swap
WASD / ↑↓←→ Move selector cursor
Space / Enter Select gem & confirm swap
H Show Hint for match
R Restart current game
Esc Return to Title Menu

Quick Actions

Game Modes

  • Timetrial: Match gems rapidly to keep the countdown bar filled. Game ends when time runs out!
  • Endless: Relaxing puzzle session with no time limits. Game ends when no valid moves remain!
